# AlmaStudio — client links

آتلیه آلما — لینک‌های اختصاصی مشتریان (شرایط و آمادگی جلسات).

## Start (localhost)

```bash
cd F:/reza/AlmaStudio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Public links

- `/links/outdoor-conditions` — شرایط فضای باز
- `/links/outdoor-prep` — آمادگی فضای باز
- `/links/studio-prep` — آمادگی جهت عکاسی
- `/links/studio-conditions` — شرایط آتلیه آلما

### Admin

- URL: `/admin`
- Default login: `admin` / `alma123` (override with `ADMIN_USERNAME` / `ADMIN_PASSWORD` in `.env.local`)
- Edits persist to `data/content.json`
